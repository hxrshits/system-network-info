# System & Network Info Tool

A Python-based command-line tool for Linux/WSL that displays useful system and network information.

The project is being developed as a lightweight system administration and networking utility.

---

## Features

- System information
- CPU information
- Memory usage
- Disk usage
- Network information
- IP address
- Listening ports
- Basic system health status

---

## Requirements

- Python 3
- Linux / WSL
- Standard Linux system utilities

---

## Usage

```bash
python3 system_info.py
```

More features and command-line options will be added as the project develops.
